Settings

System configuration

General
Your public Telegram @username, without the @. Leave blank to hide the Telegram button.
Organisations
Manage the list of organisations, their accent colours, and their map location (address & pin). Used in dropdowns, directory, user profiles, and the company locations map across the system.
Sites
Extra named locations that are not organisations — they never appear in the Directory or its dropdowns. Use these for your own branches, depots, or other sites you just want plotted on the locations map alongside organisations.
Session timeout
Automatically sign out inactive users after this many minutes. Applies to both the admin panel and the client portal. Changes take effect on the next login.
minutes
(1 – 1440 · default 30)
Application version
Shown in the footer across all pages. This now auto-bumps by one (e.g. 3.5 → 3.6) every time deploy-to-github.bat pushes a change — you'll be prompted to accept or override the number at deploy time. You can also set it directly here whenever you like; either way just updates the same value.
Next ticket number
Set the next ticket number to be assigned. Use this to reset or continue a sequence after a migration or data import.
Ticket categories
Manage categories available when submitting tickets on both the client portal and admin panel. Changes are saved to the database immediately.
Canned responses
Predefined reply templates available when responding to tickets. Drag to reorder.

Telegram notifications
—
Configure which events send Telegram alerts and manage recipient chat IDs for all admins and agents.
Triggers
Recipients
Get each recipient's chat ID: have them message @helpdesk_martillo_bot once, then visit https://api.telegram.org/bot<YOUR_BOT_TOKEN>/getUpdates (replace <YOUR_BOT_TOKEN> with the token from @BotFather — this is different from the bot's username) and copy the chat.id.
Database backup
Exports every table in the database as a JSON file, generated directly from Supabase and downloaded to your browser. New tables are picked up automatically — nothing to configure when the schema grows.
Not included: Auth accounts (emails/passwords), Storage files (attachments — only their URLs are captured), and the database schema itself (RLS policies, functions, triggers). For full disaster-recovery coverage, pair this with Supabase's own project backups or a periodic pg_dump.
CSV export includes: ticket number, subject, status, priority, category, requester name & email, assigned tech, organisation, created date, and last updated. Dates are formatted for Excel. One row per ticket.

Map
Controls the ambient clouds, boats, and planes that drift across the company locations map. Intensity affects their size/visibility; Frequency affects how often each one appears. Applies live on locations.html — no deploy needed.
🌊 Water region
Boats, ripples, and dolphins are confined to these boxes rather than actual water pixels — browsers block reading pixel colour data from OpenStreetMap's tiles (a CORS security restriction, not something configurable). Click "Redraw region", then drag on the map. Hold Shift while dragging to add another region instead of replacing the existing one(s) — useful for separate bodies of water like a bay and a marina.
Drag to draw a region

Settings

System configuration

General
Reports baseline
Set the starting ticket number for all reports. Tickets with a lower number will be excluded from charts and statistics. Useful for ignoring test or legacy tickets.
# From ticket
Default: 1 (all tickets included)
Session timeout
Automatically sign out inactive users after this many minutes. Applies to both the admin panel and the client portal. Changes take effect on the next login.
minutes
(1 – 1440 · default 30)
Application version
Set the version number displayed in the footer across all pages.
Organisations
Manage the list of organisations available in dropdowns across the system. Changes are saved to the database immediately.
Ticket categories
Manage categories available when submitting tickets on both the client portal and admin panel. Changes are saved to the database immediately.
Database backup
Export all tickets, profiles, and comments as a JSON file. The backup is generated directly from your Supabase database and downloaded to your browser.
